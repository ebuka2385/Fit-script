# FitScript

An intelligent training system for serious lifters. FitScript goes beyond workout logging — it analyses your training data using sports science models to predict injuries, forecast strength gains, track recovery, and generate personalised AI coaching reports.

---

## Features

### Training Intelligence
- **ACWR (Acute:Chronic Workload Ratio)** — 7-day vs 28-day rolling load per muscle group, colour-coded into safe/caution/danger zones using Gabbett (2016) research
- **Banister Fitness-Fatigue Model** — exponential decay model separating fitness (τ=45d) from fatigue (τ=15d) to predict performance readiness
- **Injury Risk Scoring** — 0–100 composite score per muscle from ACWR, volume spikes, and training frequency
- **Recovery Forecast** — projects exactly when each muscle clears 70% of post-session fatigue using the Banister decay constant

### Strength Analytics
- **1RM Estimation** — Epley formula applied per set across all logged exercises
- **Polynomial Regression** — degree-2 least-squares fit on 1RM history projecting strength at +14/+28/+56 days with 95% confidence intervals
- **Strength Percentile Ranking** — compares your lifts against ExRx population standards (Untrained → Novice → Intermediate → Advanced → Elite), bodyweight-adjusted

### Visualisations
- **SVG Muscle Map** — hand-drawn front/back body heatmap where each muscle group glows green/amber/red based on injury risk
- **Strength Forecast Chart** — regression curve with confidence band and future projection
- **Volume Radar** — hexagonal distribution chart across all six muscle groups
- **Banister Chart** — fitness vs fatigue vs performance curves over full training history
- **Recovery Timeline** — animated progress bars per muscle showing % recovered and ready date

### AI Coaching
- **AI Training Report** — one-click report generated by Claude Sonnet via LangChain. Analyses all your data and writes a structured coaching report: today's training call, recovery status, strength progression, injury risk alerts, and coach's summary
- **Report History** — all generated reports saved to the database, expandable and deletable from the dashboard

### User & Export
- **Multi-user auth** — session-based login/signup with hashed passwords, fully isolated data per account
- **PDF Export** — downloads a formatted A4 report with stats, recovery table, ACWR, strength estimates, workout history, and latest AI report
- **Collapsible sections** — every dashboard panel collapses independently with state saved to localStorage

## Getting Started

### Prerequisites
- Python 3.12+
- [uv](https://docs.astral.sh/uv/) — `curl -LsSf https://astral.sh/uv/install.sh | sh`
- An Anthropic API key (for AI reports)

### Setup

```bash
# Clone and enter the project
git clone <repo-url>
cd FitScript

# Add your API key
echo "ANTHROPIC_API_KEY=your_key_here" > .env

# Install dependencies and run
./run.sh
```

`run.sh` starts two independent FitScript instances in parallel on the same machine — one on port 8000 and one on port 8001. Both share the same SQLite database but run as separate processes, so you can be logged into two different accounts simultaneously (useful for testing or side-by-side comparison).

- **Account 1** → http://localhost:8000
- **Account 2** → http://localhost:8001

Or run a single instance:

```bash
uv run python3 app.py
```

Then open http://localhost:8000
